# git-bug hard fork

This repository is an independently maintained hard fork of
[`git-bug`](https://github.com/git-bug/git-bug), a distributed, offline-first
issue tracker stored in Git. It is not maintained by or affiliated with the
upstream project.

This fork is based on upstream commit
